# AI Hackathon Practical Toolkit

공개 자료를 활용해 실무형 AI 과제를 수행하기 위한 프롬프트·스킬·하네스·템플릿 모음입니다.

**주의:** 실제 과제 지시문과 시험 규정이 항상 우선합니다. 시험 문제·답안·비공개 자료를 저장하거나 외부로 전송하지 마세요. 시험 환경에서는 허용된 공개 자료만 필요한 범위에서 사용하고 Git Push, 개인 PC 파일 업로드, 외부 브라우저 직접 접근 등 금지사항을 준수하세요.

## 폴더
- `prompts/`: 과제 유형별 Codex 프롬프트
- `skills/`: 데이터·원가·웹/API·검증 지침
- `harness/`: 수행 절차와 시간 체크리스트
- `templates/`: 분석계획·결과보고·검증 기록
- `scripts/`: CSV 품질 프로파일링 코드
- `examples/`: 프롬프트 사용 순서 예시

## 빠른 사용
1. 과제 지시문과 README를 읽고 제출물·제약사항을 추출합니다.
2. 폴더와 파일을 탐색해 실제 입력 경로를 확인합니다.
3. 과제 유형에 맞는 프롬프트를 적용합니다.
4. 분석·구현 전에 계획을 받고, 확인 후 실행합니다.
5. 원본 데이터, 업무 기준, 계산 로직, 실행 결과를 교차 검증합니다.
6. 필수 결과물을 지정된 경로와 형식으로 저장하고 열어 확인합니다.

경로를 추측하지 말고, 원본을 덮어쓰지 말고, 확인된 사실·추정·미확인 사항을 구분하세요. AI의 자체 검증도 최종 정답으로 간주하지 마세요.

## 출제 유형 참고
이 저장소의 유형 분류는 준비를 위한 시나리오이며 실제 출제 예측이나 공식 출제 범위가 아닙니다.
