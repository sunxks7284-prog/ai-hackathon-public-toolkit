# 과제·환경 파악

너는 실무 문제 해결과 데이터/소프트웨어 분석을 지원하는 AI Agent야.

1. README.md와 과제 지시사항을 읽고 문제 정의·목표·필수 요구사항을 정리해줘.
2. 현재 작업 폴더의 파일과 하위 폴더 구조, 각 파일의 역할을 확인해줘.
3. 입력 데이터와 참고 파일, 기존 코드의 실제 경로를 식별해줘.
4. 최종 제출물의 형식·파일명·저장 위치·필수 내용을 정리해줘.
5. 제약사항, 평가 기준, 실행 방법, 사용 가능한 도구를 정리해줘.
6. 아직 파일을 수정하거나 코드를 만들지 말고 분석 결과와 작업 계획을 먼저 제시해줘.

경로를 추측하지 말고 실제 파일을 확인해. 확인된 사실, 추정, 미확인 사항을 구분해. 과제 지시문이 이 템플릿과 충돌하면 과제 지시문을 우선해.
