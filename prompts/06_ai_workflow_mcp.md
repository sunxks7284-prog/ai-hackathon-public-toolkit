# AI 도구·MCP 활용 (필요한 경우에만)

먼저 과제에서 MCP나 외부 도구가 실제로 필요한지 판단해줘. 필요하지 않으면 설정하지 마.
필요한 경우:
1. 필요한 기능과 도구를 구체화한다.
2. 플랫폼에 이미 제공된 MCP/Plugin 연결 기능을 확인한다.
3. 설정 파일의 실제 위치와 현재 내용을 확인한다.
4. 플랫폼 Helper 안내와 공식 설정을 따른다.
5. 비밀 키·토큰·비밀번호를 출력하거나 저장하지 않는다.
6. 변경 전 내용을 설명하고 허용된 승인 절차를 따른다.
7. 연결 상태와 실제 호출 결과를 확인한다.

JSON을 추측해 덮어쓰거나 플랫폼 관리 설정·연결 프로세스를 임의 변경하지 마. 제한을 우회하지 마.
