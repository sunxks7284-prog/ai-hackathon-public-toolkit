# API 연동 및 웹서비스

먼저 README와 기존 프로젝트를 확인하고 기존 기술 스택·실행 명령을 우선해줘.

1. API 목적, 엔드포인트, 요청 방식, 인증, 응답 형식을 확인한다.
2. 키·토큰을 코드나 로그에 하드코딩하지 않는다.
3. 실패 응답, 빈 응답, 타임아웃, 잘못된 데이터 형식을 처리한다.
4. 핵심 기능부터 최소 단위로 구현한다.
5. 서버 실행 명령과 실제 포트를 확인한다.
6. 플랫폼 내부 Browser에서 실제 포트·경로로 미리보기를 연다.
7. 버튼·입력·검색 등 핵심 기능을 직접 테스트한다.
8. 실행 방법과 제한사항을 문서화한다.

데이터 분석은 Python을 우선 고려하고, 기존 JavaScript 프로젝트나 웹 서버는 Node.js를 고려해. 기술 선택 이유를 설명해줘. 출력은 실행 가능한 프로젝트, 실행 방법, 테스트 및 브라우저 검증 결과야.
