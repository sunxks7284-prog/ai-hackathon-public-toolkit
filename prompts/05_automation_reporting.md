# 자동화 및 보고서 생성

반복 업무 자동화를 위해 입력 파일, 출력 형식, 처리 규칙, 실행 주기를 먼저 확인해줘.
1. 파일명·열 이름·날짜·단위·인코딩 변동 가능성을 확인한다.
2. 중복 실행 시 중복 결과가 생기지 않도록 설계한다.
3. 실패한 입력과 처리 건수를 로그로 남긴다.
4. 원본을 보존하고 결과는 별도 폴더에 저장한다.
5. 샘플 입력으로 정상·예외 케이스를 테스트한다.
6. 실행 방법과 오류 대응을 문서화한다.

과제에 없는 자동 발송·외부 전송·스케줄 등록은 하지 마. 외부 연동은 과제에서 허용된 경우에만 수행해줘.
