# Skill: Cost Engineering
분석 전 원가 범위, 표준/실제/예산 기준, 통화·단위·기간, 투입/생산/양품/출하 수량, 고정비·변동비, 배부 기준을 확인한다.

- 단위당 원가의 분모를 명시한다.
- 단순 평균과 생산량 가중평균을 구분한다.
- 가격·수량·믹스·수율 요인 분해는 데이터가 뒷받침하는 범위에서만 한다.
- ROI·회수기간 산식과 기간을 명시한다.
- 절감액의 연간화, 램프업, 일회성/반복성을 구분한다.
- 추정치와 실적치를 혼합하지 않는다.
- 모든 가정과 민감도 변수를 공개한다.

결과는 결론 → 수치 근거 → 계산식 → 가정 → 민감도 → 리스크 순서로 설명한다.
