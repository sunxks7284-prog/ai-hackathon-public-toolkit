# Execution Harness

## 규칙 우선순위
시험 운영 규정·과제 지시문 > README·데이터 사전 > 실무 담당자 설명 > 일반 관행 > AI 추정.

## Discover
과제·README, 폴더 트리, 파일 역할, 입력 데이터, 제출물·저장 위치·실행 조건을 확인한다.

## Clarify
불명확한 KPI·업무 용어를 실무 담당자에게 질문한다. 답변을 과제 지시문과 데이터 정의에 대조한다.

## Plan
작업을 작은 단계로 분해한다. 기존 기술 스택을 우선하고 구현 전 계획을 보고한다.

## Build
원본을 보존하고 작은 단위로 구현·실행한다. 불필요한 패키지·구조 변경을 피한다.

## Verify
계산식·기간·단위·분모를 확인하고 원본에서 독립 재계산한다. 테스트·실행·Browser 미리보기를 확인한다.

## Deliver
필수 파일·경로·형식·저장 상태를 확인한다. 결론·근거·가정·한계를 기록한다.
